<Warning>
  **Advanced use only.** These endpoints change campaign logic directly. Use them only when you know how the configuration you change works, because a wrong call can change how a live program behaves. For day-to-day configuration, use the [Management API](/api-reference/getting-started/api-overview#management-api) or My Extole.
</Warning>

The Management API covers the configuration most programs need. The Management Expert API covers the rest: campaign controllers with their triggers and actions, flow steps, advanced component types, component grants and subscriptions, event prehandlers, report types, and report runners.

## Before You Call It

- **Authenticate as you do for the Management API.** The same access tokens work. See [Authentication](/api-reference/getting-started/authentication-overview).
- **`PUT` merges.** A field you leave out of the body keeps its stored value. A field that holds a list or a map is replaced when you send it, so send every member you want to keep.
- **Read the operation's own page first.** Each operation lists its parameters, request and response schemas, and the errors it returns.

## Available Operations

See the **Management Expert API** section in the navigation. For example, [Create a campaign controller](/api-reference/expert/campaign-controllers/create-a-campaign-controller) adds a controller to a campaign, and the Campaign Controllers Triggers and Campaign Controllers Actions groups configure what it does.
