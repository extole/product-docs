<Warning>
  **Advanced use only.** Many of these endpoints change campaign logic directly. Use them only when you know how the configuration you change works, because a wrong call can change how a live program behaves. For day-to-day configuration, use the [Management API](/api-reference/getting-started/api-overview#management-api) or My Extole.
</Warning>

The Management API covers the configuration most programs need. The Management Expert API covers the rest, including campaign controllers with their triggers and actions, flow steps, advanced component types, component grants and subscriptions, event prehandlers, some report type and report runner operations, and other expert operations such as extended cores, JWT client key verification, OAuth code exchange, DKIM record generation for email domains, and a set of consumer-side operations.

## Before You Call It

- **Authenticate as you do for the Management API.** The same access tokens work, except for the consumer-side operations, such as downloading a profile asset, which take a consumer access token. Person asset downloads also work with no token, and then return only the person's public assets. See [Authentication](/api-reference/getting-started/authentication-overview).
- **`PUT` merges.** A field you leave out of the body keeps its stored value, except a field the operation's request schema marks required, which every request must send. A field that holds a list or a map is replaced when you send it, so send every member you want to keep.
- **Read the operation's own page first.** Each operation lists its parameters, request and response schemas, and most of the errors it returns.

## Available Operations

See the **Management Expert API** section in the navigation. For example, [Create a campaign controller](/api-reference/expert/campaign-controllers/create-a-campaign-controller) adds a controller to a campaign, and the Campaign Controllers Triggers and Campaign Controllers Actions groups configure what it does.
