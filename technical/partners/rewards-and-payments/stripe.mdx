## Overview

Extole Offers for Stripe rewards a person through the Stripe account you already use. A reward is either a credit on the Stripe customer's balance or a one-time promotion code for a coupon that already exists in Stripe. Stripe sends the events you select, Extole decides whether a reward is earned, and Extole calls the Stripe API to issue it. There is no separate payout system.

Install the Stripe App, [Extole Offers](https://marketplace.stripe.com/apps/com.extole.stripe-offers-v4). In My Extole, the Stripe integration's **Connect** button opens that install page. When you install the app, Stripe creates a restricted key with only the permissions the app lists. You give that key to Extole, and the app's settings page helps you send Stripe events to Extole.

## Prerequisites

| Requirement | Description |
| --- | --- |
| Stripe account | An active Stripe account. Use a sandbox account to test. |
| Stripe coupon | Required only for promotion-code rewards. Create the coupon in Stripe before you configure the supplier. |
| Extole access token | An access token with the User Support scope, created in **Security Center**. The webhook URL uses it. |

## Install the Integration

1. Install Extole Offers in Stripe and accept its permissions. Stripe opens the app's settings page.
2. On that page, click **View API keys** and copy the restricted key (`rk_`). Stripe gave it write access to Customers and Promotion codes, and read access to Coupons, Subscriptions, and Webhook endpoints.
3. In My Extole, open **Security Center** and click **New Key**. Choose the **Webhook** type and the **Password** algorithm, paste the restricted key, and save.
4. Open **Partners** > **Stripe**, install the integration, select the key from the previous step in **Stripe Secret Key**, and publish.
5. Back in the app's settings page in Stripe, paste the Extole access token and click **Build webhook URL**. The token stays in your browser. The app does not save it. In the Stripe Dashboard, open **Developers** > **Webhooks**, add a destination with that URL, and select the events in the table below. The settings page shows the destination once Stripe has it, and lists any event it does not send.
6. Open **Stripe** > **Rewards** in My Extole and add a supplier. Then open **Programs**, edit the campaign, and attach that supplier to the step that should issue the reward.

The **Reward history on customer pages** switch in the app settings is optional. It shows the balance credits and promotion codes Extole issued on each Stripe customer page.

To replace the webhook token, create a new access token, build a new URL, and update the destination in Stripe. Then delete the old token in **Security Center**. To uninstall, remove the app in Stripe, delete the Extole destination under **Developers** > **Webhooks**, and remove the Stripe integration in **Partners**.

<Note>
Extole is not an OAuth provider for Stripe, so there is no OAuth connect step. The restricted key Stripe creates at install is the only credential Extole uses to call Stripe.
</Note>

## Reward Types

Both suppliers live on the Stripe integration. Add the one you need from **Rewards**.

### Customer Balance

Credits the Stripe customer's balance. Set the currency and the face value. Turn on dynamic value when the credit should be a percentage of the rewardable event. Set that percentage to 100 to use this supplier as a [Reward Bank](/technical/platform-integrations/extensions/reward-bank/reward-bank-configuration-guide) redemption reward.

Extole posts a balance transaction on the Stripe customer. The amount is negative, in the currency's minor units, so the credit reduces the next invoice. Zero-decimal currencies such as Japanese yen, Korean won, and Chilean peso are not scaled. Three-decimal currencies such as Kuwaiti dinar are scaled by 1,000, as Stripe requires. The Stripe balance transaction id is stored as the reward's partner reward id.

### Promotion Code

Issues a one-time Stripe promotion code for a coupon you already created. The code is the reward's partner reward id, so emails, the reward center, and reports show it the way they show any other coupon.

Select the coupon, set the face value type and face value so they match that coupon, and optionally limit the code to the customer's first transaction or set a number of days before it expires. Zero days means the code does not expire.

Dynamic value is not available on this supplier. A Stripe coupon's amount is fixed when you create the coupon, so Extole cannot change it per event. Use Customer Balance when the amount has to follow the event or a Reward Bank redemption.

Extole creates a Stripe promotion code with a redemption limit of one, the Stripe customer, and metadata that records the Extole reward id. Retries send the Extole reward id as the Stripe idempotency key, so a retry does not create a second code.

A reward fails, and is not retried, when the person has no Stripe customer id or the id does not start with `cus_`.

## Events Extole Receives

The webhook posts each Stripe event to `https://api.extole.io/v6/events/stripe_event`. Extole renames it and exposes it as a trigger you can use in a Flow Builder campaign.

| Stripe event | Extole event | What it means |
| --- | --- | --- |
| `payment_intent.succeeded` | `stripe_payment_intent_succeeded` | A one-time payment completed. |
| `checkout.session.completed` | `stripe_checkout_session_completed` | A Checkout Session finished. |
| `customer.subscription.created` | `stripe_customer_subscription_created` | A customer started a subscription. |
| `customer.subscription.updated` | `stripe_customer_subscription_updated` | A subscription changed. |
| `customer.subscription.deleted` | `stripe_customer_subscription_deleted` | A subscription was canceled. |
| `invoice.paid` | `stripe_invoice_paid` | A subscription invoice was paid. |
| `charge.refunded` | `stripe_charge_refunded` | A charge was fully or partly refunded. |
| `customer.discount.created` | `stripe_customer_discount_created` | A promotion code was applied. |

Extole copies these fields onto the event when Stripe sends them: `partner_user_id` from the Stripe customer id, `email` from `customer_email`, `currency`, `status`, `amount`, invoice amounts, the subscription id, and the plan amount. A subscription that moves from `trialing` to `active`, or is created already `active`, is marked as a new activation.

## How a Promotion Code Is Redeemed

1. Extole issues the code and stores it as the reward's partner reward id. The reward stays earned.
2. Stripe sends `customer.discount.created`, or `checkout.session.completed` with a promotion code. Extole reads the promotion code and asks Stripe for that code.
3. When the code's metadata contains the Extole reward id, Extole redeems the reward. Emails and reports then show it as redeemed, the same way they show any other coupon.

If Stripe cannot find the code, or the code has no Extole reward id, the reward stays earned.

## Identity

`partner_user_id` is the Stripe customer id (`cus_`). When the Stripe event includes `customer_email`, Extole also records `email`.

You can copy the advocate lookup controller into a marketing campaign. On a share, it looks up Stripe customers by the person's email. One match writes `partner_user_id`. Several matches use the earliest customer Stripe returns. No match leaves the person without a Stripe customer id, and a later reward for that person fails until an id is present.

## FAQs

**Does the person need to exist in Stripe before they can receive a reward?** Yes. Extole issues the reward to the Stripe customer on the event. Create the customer in Stripe first, or resolve them with the email lookup before the reward is earned.

**What if the restricted key is missing or rejected?** The Stripe call fails and Extole marks the reward failed. Copy the key again from **View API keys** in the app settings, save it as a new key in **Security Center**, select it in **Stripe Secret Key**, and publish the integration again.

**Can a promotion code be a percentage of the cart?** No. The coupon amount is fixed in Stripe. Use Customer Balance with dynamic value for a percentage, including a Reward Bank redemption at 100 percent.
