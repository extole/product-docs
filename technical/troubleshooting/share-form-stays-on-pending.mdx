# Overview

An advocate enters their details on your share experience and clicks submit. The button changes to **Pending** and stays there. This page explains what finishes a submit, why eligibility is not the cause, and how to find the edit that stops the creative's script.

## How a Submit Finishes

When an advocate submits the form, the share experience's script updates the advocate's profile and asks Extole for their share link. The button leaves **Pending** when the script gets its answer, in one of three ways:

- **The advocate can share.** The share experience shows their share link and share options.
- **The advocate is not eligible.** Extole returns no share link, for example because the campaign requires an audience the advocate is not in. The share experience shows your ineligibility message.
- **The profile update fails.** The button shows an error.

An advocate who is not eligible therefore sees the ineligibility message, not a button that stays on **Pending**. When the button never finishes, the script stopped before it received an answer, whoever the advocate is.

## Find What Stopped the Script

1. Open the share experience in a desktop browser and open the browser's developer console.
2. Submit the form with the details that leave the button on **Pending**.
3. Read the error the console shows. It names the script and the line that failed.

When the creative has been edited by hand, compare its files with the library template the component was installed from, and start with the files that differ. A common cause is a panel template that no longer includes a partial that a script needs. For example, the share experience's script for the share link looks for the element that the `share-link` partial in `panel-home.html` renders. If the template no longer includes that partial, the script fails while the share experience starts, and the scripts that start after it never run.

## What to Do

Restore what the edit removed, or change the script so that it no longer needs it. Make the change in the campaign's draft and check the share experience in the draft before you publish: submit once as an eligible advocate and once as an advocate who is not eligible.

If every file matches the library template and the button still stays on **Pending**, contact Extole Support with the console error, the page address, and the campaign name.
