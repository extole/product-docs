## Overview

[//]: # "How do I upload files to Extole?"

Our Batch Jobs page, located in the My Extole Tech Center, offers a powerful self-service experience for your file upload needs. This page allows you to quickly and reliably upload file-based events and automate jobs of large files without needing to coordinate with our Support team.

For a recurring inbound file pipeline that should detect, validate, and process files as they arrive, install [File Integration](/technical/platform-integrations/extensions/file-integration) instead.

## Creating a New Job

[//]: # "How do I create a batch job to upload files to Extole?"

Click on the + New Batch Job button to start the job creation process. A drawer-style window will slide out from the right-hand side of your screen with all of the necessary fields to fill in for your job.

### Advanced Fields

Click **Advanced** in the drawer to open the optional fields.

| Field | Description |
| :---------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Event Name | The event name to use for the rows in your file. Leave it empty to take the event name from each row's `event_name` value. |
| Override event names in the source file | Turn this on to send every row as the name in **Event Name**. Leave it off and **Event Name** applies only to rows that carry no `event_name` value of their own. |
| Event Data | Name and value pairs added to every event the job creates. |
| Tags | Labels for finding and grouping the job later. |

### How Extole Names Each Event

Extole chooses the event name for each row in this order:

1. **Event Name**, when **Override event names in the source file** is on. Every row creates this event, and any `event_name` column in the file is ignored.
2. The row's own `event_name` value, when your file has an `event_name` column.
3. **Event Name**, when the override is off. These rows carry no `event_name` value of their own.
4. `unknown`, when you left **Event Name** empty and the row carries no `event_name` value.

<Warning>
A job created with no **Event Name**, from a file with no `event_name` column, sends every row as `unknown`. The job still completes with every row valid and no errors, because `unknown` is a real event name — it is one that no campaign listens for, so no journey starts and no reward is sent. Open the job's detail view and read **Event Names**: if it reads `unknown`, add an `event_name` column to your file or set **Event Name** on the job, then upload the file again under a new name.
</Warning>

For the columns an event file carries, see [File-based Events](/technical/platform-integrations/files/file-based-events).

## Searching for a Job

[//]: # "How do I search for an uploaded file in Extole?"

You can now search for your jobs by typing keywords into the search bar and applying search filters. 

![Screenshot showing You can now search for your jobs by typing keywords into the search bar and applying search filters.](/images/extole/74ac54819ce731e0fc240cf93bdfa3cc8d2b4142576158a0b291d7cdbce9245f.png)

Apply filters to your search by changing the “Search by:” dropdown criteria. For example, if you select Search by: User and click on the bar, it will generate a list of users for you to browse. Selecting a user will show you all of the jobs that user has created.

## Sorting Jobs by Status

[//]: # "How do I search for a file based on its upload status?"

In the jobs table, you have the option to sort your jobs based on status. You can select any number of statuses.

![Screenshot showing In the jobs table, you have the option to sort your jobs based on status. You can select any number of statuses.](/images/extole/1b8cc0b060f965d39f2b61521440c9ad944c403132c26ad0b6c34994cc3d3de3.png)

### Job Statuses

The job statuses include pending, in progress, done, failed, canceled, and expired.

| Status      | Description                                                                                                                     |
| :---------- | :------------------------------------------------------------------------------------------------------------------------------ |
| Pending     | The job is in our system and getting ready to process. This preparation phase can take up to a couple of minutes.               |
| In Progress | The job is actively being processed by our system. The duration of the processing period is dependent on the size of the file.  |
| Done        | The job has been successfully completed.                                                                                        |
| Failed      | The job was unable to be processed. This is most likely due to issues with your file format or duplicated files.                |

A file is rejected as a duplicate when its name matches a file already uploaded to your account, including a file that has since expired. A naming scheme that repeats, such as a month and day with no year, therefore fails on the anniversary of an earlier upload, and the feed for that day is lost. Include the year, or another value that never repeats, in every file name.
| Canceled    | The job was canceled by you before it was completed.                                                                            |
| Expired     | The job was uploaded more than 90 days ago. These files are removed from our system, but we do retain history that the job ran. |

## Viewing Job Details

[//]: # "How do I details about an uploaded file in Extole?"

Each job in the table has a detailed view. Clicking on a job will open a drawer-type window from the right-hand side of your screen that lists more in-depth information about the job.

![Screenshot showing Each job in the table has a detailed view. Clicking on a job will open a drawer-type window from the right-hand side of your screen that lists more in-depth...](/images/extole/18423ed8dd3813f69354173053958b4765cfdca407aa78519d2d8189898543ce.png)

### Detailed View

Information displayed the detailed view of a job includes the following:

* Name
* Source (clicking this link will download the file)
* Type
* Status
* Valid/Invalid Rows
* Start/Completed Time
* Tags
* Event Names (if all events in your file are the same type)
