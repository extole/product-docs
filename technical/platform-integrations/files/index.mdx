## Overview

Exchanging data with Extole via file transfer is a great integration option if your business operates online, as well as over the phone or in person. You can send bulk event files as a recurring pipeline, as a one-off upload in the Tech Center, or by dropping them on an SFTP server.

## Recurring Inbound File Pipelines

For an ongoing CSV or SFTP event feed — detect the file, validate its headers, and create events automatically — install the [File Integration](/technical/platform-integrations/extensions/file-integration) extension. That is the path for "create a file integration."

The SFTP server itself is still created in the Tech Center; the extension reads from a connection you already have. See [Extole SFTP Server](/technical/platform-integrations/files/extoles-sftp-server).

The column layout for event files is on [File-based Events](/technical/platform-integrations/files/file-based-events).

## Upload Files Directly to Extole

In the Tech Center of your My Extole account, you have the option to directly upload files of key program events. Our Batch Jobs page offers a powerful self-service experience for your file upload needs. This page allows you to quickly and reliably upload file-based events and automate jobs of large files. See [General File Uploads](/technical/platform-integrations/files/general-file-uploads).

## Send Files via SFTP

Also through the My Extole Tech Center, you can automate batch files via Secure File Transport Protocol (SFTP). This is a generally available protocol that provides strong encryption when transferring files that may contain Personally Identifiable Information (PII) to and from Extole.

You can create [Extole SFTP servers](/technical/platform-integrations/files/extoles-sftp-server) as well as set up [external servers](/technical/platform-integrations/files/external-sftp-servers) to which you would like to send report data.
