Connect your Extole programs to Claude Desktop and manage referrals with natural language.

Claude Desktop is the app version of Anthropic's Claude. Once connected to Extole, you can run reports, check program performance, and make changes to your programs directly in Claude — without opening My.Extole.

## Requirements

Every person who wants to use the Extole MCP must complete setup individually.

You'll need:

- The latest version of [Claude Desktop](https://claude.ai/download) installed
- An active Extole user account
- MCP access enabled for your Extole organization (contact your administrator if unsure)

---

## Setup

**Step 1: Open Claude Desktop settings**

In Claude Desktop, navigate to **Settings > Connectors**.

**Step 2: Add a custom connector**

Click **Add custom connector**.

**Step 3: Configure the connector**

Fill in the following:

- **Name** — Enter `Extole`
- **Remote MCP Server URL** — Paste the following:

`Extole`

Click **Add**.

**Step 4: Authorize the connection**

Claude Desktop will add the connector to your connector list.

1. Click **Connect** next to the Extole connector.
2. Your browser will open to an Extole authorization page.
3. Review the permissions and click **Authorize**.

Extole will create an access token linked to your user account.

**Step 5: Verify the connection**

In a chat, click the **+** (plus) icon, then **Connectors**. Your Extole connector should appear as enabled.

---

## Using the MCP

Once connected, Claude Desktop uses the Extole MCP automatically when you ask questions about your programs or request changes.

**Step 1:** Open a chat and enter a prompt. For example:

> *"Show me the performance report for my refer-a-friend program this month."*

> *"What reward is currently configured for the friend offer in my main campaign?"*

> *"Increase the advocate reward in the summer promotion to $20."*

**Step 2:** The first time Claude uses an Extole tool, you'll be prompted to approve it. Click **Allow once** or **Allow always** to proceed.

**Step 3:** Claude will call the appropriate Extole MCP tools, retrieve or update data, and return the result in the chat.

<Warning>
**Write operations**

Actions that modify programs, rewards, or campaign components execute immediately under your Extole permissions and are recorded in the Extole change log. Review prompts carefully before approving write operations.
</Warning>
