Connect Extole to Microsoft's AI platforms so your teams can manage referral programs using natural language — either directly in Microsoft 365 Copilot Chat or as part of a custom Copilot Studio agent.

There are two integration paths depending on your use case:

- **Microsoft 365 Copilot Chat** — An admin creates a custom federated connector in the Microsoft 365 admin center. Users can then ask Copilot Chat questions about Extole's documentation. Copilot Chat cannot read your program data — see the note below.
- **Copilot Studio** — Agent builders connect Extole MCP tools to a custom agent. Best for teams building purpose-built Copilot experiences that can also write back to Extole (update rewards, modify programs, etc.).

<Info>
**Not available from Copilot's own settings**

Extole is not listed under **Customize > Plugins** in Copilot, and Agent Builder (**Agents > New agent**) cannot add an MCP server directly. Use one of the two paths below.
</Info>

---

## Microsoft 365 Copilot Chat

Microsoft 365 Copilot supports **custom federated connectors** — real-time connections to an MCP server, configured by an admin in the Microsoft 365 admin center. Once deployed, each user connects Extole as a source in Copilot Chat and signs in with their Extole account.

<Warning>
**Documentation questions only**

Custom federated connectors only use tools that the MCP server marks as read-only. Extole's documentation tools are read-only, so Copilot Chat can answer questions from the Extole documentation. The tool that reads program, report, and reward data can also make changes, so Copilot Chat does not use it. To ask about your own programs, use [Copilot Studio](#copilot-studio).
</Warning>

<Info>
**Who this is for**

This section is for **Microsoft 365 Global Administrators or AI Administrators**. Users only need to sign in to Extole when Copilot first asks.
</Info>

### Requirements

- A Microsoft 365 Copilot license
- Global Administrator or AI Administrator role in the Microsoft 365 admin center
- Access to the [Teams Developer Portal](https://dev.teams.microsoft.com/)
- MCP access enabled for your Extole organization (contact your Extole administrator if unsure)

### Step 1: Get an Extole client ID and secret

Microsoft needs a client ID and client secret for Extole. Extole's sign-in service issues them on request — there is no form to fill in and nobody at Extole needs to approve it. Run this once from any terminal:

```bash
curl -s -X POST https://idp.extole.com/connect/register \
  -H 'Content-Type: application/json' \
  -d '{
    "client_name": "Microsoft 365 Copilot",
    "redirect_uris": ["https://teams.microsoft.com/api/platform/v1.0/oAuthRedirect"],
    "grant_types": ["authorization_code", "refresh_token"],
    "response_types": ["code"],
    "token_endpoint_auth_method": "client_secret_post",
    "scope": "openid profile email"
  }'
```

The response contains a `client_id` and a `client_secret`. Store the secret somewhere safe — it is shown only once.

### Step 2: Register the OAuth connection in the Teams Developer Portal

1. Sign in to the [Teams Developer Portal](https://dev.teams.microsoft.com/).
2. Select **Tools > OAuth Client Registration**.
3. Select **+ New OAuth connection**.
4. Fill in the following fields:

| Field | Value |
|---|---|
| **Registration name** | `Extole` |
| **Base URL** | `https://mcp.extole.com` |
| **Restrict usage by org** | `My organization only` |
| **Restrict usage by app** | `Any Teams app` |
| **Client ID** | The `client_id` from Step 1 |
| **Client secret** | The `client_secret` from Step 1 |
| **Authorization endpoint** | `https://idp.extole.com/oauth2/authorize` |
| **Token endpoint** | `https://idp.extole.com/oauth2/token` |
| **Refresh endpoint** | `https://idp.extole.com/oauth2/token` |
| **Scopes** | `openid profile email` |

5. Enable **Proof Key for Code Exchange (PKCE)**.
6. Click **Save**.

After saving, copy the **OAuth client registration ID**. You need it in the next step.
### Step 3: Create the connector in the Microsoft 365 admin center

1. Sign in to the [Microsoft 365 admin center](https://admin.microsoft.com/).
2. In the left pane, select **Copilot > Connectors**.
3. Select the **Gallery** tab.
4. Under **Created by your org**, find the **Create a new connector** tile and click **Add**.
5. On the **Custom connector** page, under **Connect to MCP server**, click **Add**.
6. Fill in the connector details:

| Field | Value |
|---|---|
| **Display name** | `Extole` |
| **Description** | `Extole referral and loyalty programs: program performance, reports, rewards, and campaign configuration.` |
| **MCP endpoint URL** | `https://mcp.extole.com` |
| **Developer name** | `Extole` |
| **Website URL** | `https://www.extole.com` |
| **Privacy policy URL** | `https://www.extole.com/privacy-policy/` |
| **Terms of use URL** | `https://www.extole.com/privacy-policy/` |
| **Authentication type** | `OAuth 2.0` |
| **Reference ID** | The OAuth client registration ID from Step 2 |

7. Click **Authorize** and sign in with your Extole account when prompted. A green check appears next to **Reference ID** when the sign-in succeeds.
8. Review the **Notice**, select the checkbox, and click **Create**.

### Step 4: Roll out to users

After creation, the connector appears on the **Your Connections** tab. To deploy it:

1. Select the Extole connector.
2. Select **Staged rollout** to test with specific users or groups first, or select **Deploy to all users** to release tenant-wide.

Changes can take up to 30 minutes to take effect.

### Step 5: Connect Extole in Copilot Chat

Each user does this once:

1. In [Copilot Chat](https://m365.cloud.microsoft/chat), click **+** in the message box, then **Change data sources**.
2. Search for `Extole` and click **Connect**.
3. Click **Continue to Extole** and sign in with your Extole account.

Copilot shows "Extole is now connected" and turns the Extole source on.

### Using Extole in Copilot Chat

Once connected, users can ask Copilot questions that draw on the Extole documentation:

> *"Using the Extole documentation, how do I add the Extole site tag to my website?"*

> *"What does the Extole Core Tag do?"*

## Copilot Studio

Microsoft Copilot Studio lets you build custom agents for your organization. By connecting an agent to the Extole MCP server, you can give that agent the ability to run Extole reports, query program configuration, and manage rewards — including write operations such as updating rewards or campaign components.

<Info>
**Who this is for**

This section is for teams building Copilot Studio agents. If you want Extole available in Copilot Chat without building a custom agent, use the [Microsoft 365 Copilot Chat](#microsoft-365-copilot-chat) path above.
</Info>

### Requirements

- Access to [Microsoft Copilot Studio](https://copilotstudio.microsoft.com/)
- A Power Platform environment with **Dataverse** provisioned. Copilot Studio shows "Dataverse isn't set up in this environment" on the **Agents** page until your Power Platform administrator provisions it.
- **Generative orchestration** enabled on your agent. In Copilot Studio, open your agent's settings and enable **Generative** under **Orchestration**.
- An active Extole user account with appropriate permissions
- MCP access enabled for your Extole organization (contact your Extole administrator if unsure)

### Setup

**Step 1: Open your agent's Tools page**

In Copilot Studio, navigate to your agent and select the **Tools** tab.

**Step 2: Add a new tool**

Click **Add a tool**, then **New tool**, then select **Model Context Protocol**. The MCP onboarding wizard opens.

**Step 3: Configure the server**

Fill in the following fields:

- **Server name** — `Extole`
- **Server description** — `Access Extole referral program data, reports, and management tools`
- **Server URL** — `https://mcp.extole.com`

**Step 4: Configure authentication**

Select **OAuth 2.0**, then select **Dynamic discovery** as the type. Copilot Studio discovers Extole's sign-in endpoints and registers itself, so you do not need a client ID or secret. Click **Create**.

**Step 5: Add the server to your agent**

On the **Add tool** dialog, select **Create a new connection**, sign in with your Extole account, and click **Add to agent**. Copilot Studio connects to the Extole MCP server and makes all available tools discoverable by your agent.

### Using the MCP in your agent

Once connected, the Extole MCP tools are automatically available for your agent to use.

> *"Show me the performance summary for our refer-a-friend program."*

> *"What's the current reward for advocates in the summer campaign?"*

> *"Increase the friend reward in campaign X to $15."*

<Warning>
**Write operations**

Actions that modify programs, rewards, or campaign components execute immediately under the authenticated user's Extole permissions and are recorded in the Extole change log. Make sure your agent's instructions say when write operations will occur, so users can confirm before proceeding.
</Warning>

## Data policies

**Copilot Chat (custom federated connector):** Access is governed by the connector's rollout settings in the Microsoft 365 admin center. Admins control which users or groups can use the Extole connector and can disable it at any time. Each user sees only what their own Extole account can see.

**Copilot Studio:** Access is governed by Power Platform connectors. If your organization applies data loss prevention (DLP) policies to Power Platform, those policies also apply to Extole MCP tool calls. Contact your Power Platform administrator if you need to allowlist the Extole connector.
