# Overview

An essential part of a successful Extole program is your ability to quickly, accurately, and completely report on it. This article describes how to configure and run the various types of Extole reports that give you access to important data generated by your programs.

 ![Screenshot showing An essential part of a successful Extole program is your ability to quickly, accurately, and completely report on it. This article describes how to configure...](/images/extole/78d87be2739648c46f68a50b27bc7ed15798e08de1c46828d5ca5391e6159652.png)

If you would like a more general introduction to our reports, please reference our [Reports Overview](/guides/platform-overview/exploring-the-reports-page).

# Standard Reports

## General Setup

1. On the main Reports page, select your category or use the search bar to find the report you are looking for.![Screenshot showing If you would like a more general introduction to our reports, please reference our Reports Overview.](/images/extole/03fd0abe0d2794479d144bbc601eee20da4062e05c311b81e2bea5c03a32a023.png)
2. Click on the name of the report to open its configuration screen. Here you will see all of the necessary configuration fields you'll need to fill out to run the report.
3. In particular, we recommend editing the Display Name to make the report easier to reference.
4. You can also choose to run the report once, which is our default, or schedule the report so that it runs each week, month, etc.![Screenshot showing In particular, we recommend editing the Display Name to make the report easier to reference.](/images/extole/2c60a651b68657baa2a1b2b731211ea4280d440f870a01a9f81983aea27e5ae5.png)
5. In the Filters section, you'll see a variety of fields depending on the type of report. Generally speaking, you'll be able to adjust the time range of data you want to be included in the report and select which programs or campaigns you want to look at.

  - Learn about dates you may be interested in capturing in our article on [Using My Timeline Dates](/guides/dashboards-and-reporting/extole-dashboards-and-metrics/using-my-timeline-dates).

6. In the Advanced section, you can choose the file format of your report, define which columns it returns, and optionally have it delivered via SFTP if you have a server set up in your account. See [Advanced Report Configuration](/guides/dashboards-and-reporting/configuring-reports/advanced-report-configuration).  
​![Screenshot showing In the Advanced section, you can choose the file format of your report, define which columns it returns, and optionally have it delivered via SFTP if you...](/images/extole/39268cb3521a00ad87b702194754e1f3f49861e0bbfa571fe6bad642e1fedad5.png)
7. Once you've finished your configuration, hit Save & Run to kick off your report.

## Download Options

Depending on the amount of data included in your report, it may take some time to run. Once it's completed, you can download the report by clicking on it and going to its details page.

If you'd like to create an automated pull on your side, the API call is also available on the details page or within the dot menu on the right-hand side of the reports table.
