# Overview

With its default configuration, the Visited Events report returns a list of transacted events where the consumer is new-to-file. You can also use it to generate a list of new-to-file registrations or conversions.

## Filters

- **Date Range:** The range of data in the report. These are trailing date and time ranges, so "last week" is the last seven days.
- **Step:** The event the person visited. Events in your program typically have an actor (a friend or an advocate) and an action.
  - For new-to-file conversions, use the `step_name` `converted`.
  - For new-to-file registrations, use the `step_name` `registered`. If your program uses email capture, it counts in the `registered` event.
  - Your transacted event depends on your program flow — it is usually whichever event you reward.
  - If a consumer is a new-to-file converter but converted multiple times in the range, the report lists their conversion in that range.

### Advanced

- **Visit Type:** Defaults to New To Client. This indicates the type of visit the person made. Filter by people you have seen for the first time (New To Client), who visited the program for the first time (New To Program), who visited the campaign for the first time (New To Campaign), or all people.
- **Quality:** Defaults to All. This indicates the quality of the event. Filter by events of all quality, only high quality, only low quality, or no quality.
- **Container:** Defaults to your production container. You can instead run the report for only people in your test container.
- **Source:** Defaults to all sources. Filter the report by the source the event originates from (for example, global header or global footer).
- **Channel:** Defaults to all channels. Filter the report by the channel the event originates from (for example, email, SMS, or Facebook).
- **Include Advocate:** Defaults to off. Toggle it on to include advocate information for the events. For example, run it for the event `registered` and toggle on Include Advocate to see the friends who registered and the advocates who referred them.
