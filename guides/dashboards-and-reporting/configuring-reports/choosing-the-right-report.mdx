# Overview

Many Extole reports include metrics like shares, signups, and conversions, but the best report depends on what you're ranking, grouping, or summarizing.

Before you choose a report, decide whether you need:

- a topline summary
- a breakdown by channel
- a breakdown by promotion source
- a person-level leaderboard
- a custom segmented metric view

## Quick Decision Guide

| If you want... | Recommended report | Why |
| --- | --- | --- |
| Overall last-month totals for shares, clicks, registrations, and conversions | [Events](/guides/dashboards-and-reporting/report-types/recommended-reports/events-report) or [Metrics](/guides/dashboards-and-reporting/report-types/recommended-reports/metrics-report) report configured for the events you need | Best for a quick summary across a selected date range |
| Shares, clicks, registrations, and conversions broken out by share method (email, link, social) | Metrics report configured by the channel dimension | Groups performance by channel |
| Shares, clicks, registrations, and conversions broken out by placement, CTA, email, or on-site source | Metrics report configured by the source dimension | Analyzes source-level contribution |
| A leaderboard of top promotion sources | [Top Promotion Sources](/guides/dashboards-and-reporting/report-types/recommended-reports/top-promotion-sources-report) report | Built to rank and compare promotion sources |
| A leaderboard of individual advocates or creators | [Influencer Stats](/guides/dashboards-and-reporting/report-types/audience-reports/influencer-stats-report), [Successful Advocates](/guides/dashboards-and-reporting/report-types/recommended-reports/successful-advocates-report), or [Active Advocates](/guides/dashboards-and-reporting/report-types/audience-reports/active-advocates-report) report | Returns one row per person with metrics like shares, signups, and conversions |
| A flexible report with custom dimensions like month-over-month, by campaign, by source, or by channel | Metrics report | Best for summary metrics with configurable segmentation |
| Detailed event-level activity for individual people or referrals | Events report | Best for row-level investigation rather than summary reporting |
| People who completed one event but not a later event | Incomplete Journey report | Best for drop-off analysis. Configure a visited event and a not-visited event to return people who reached one point in the journey but did not complete the later action. Prefer it when the question uses phrases like "registered but did not convert," "started but did not finish," or "did not reach the next step." See [Understanding Extole Journeys](/guides/dashboards-and-reporting/understanding-extole-journeys-extended-reference-for-reporting). |

## Leaderboards and Top Entities

When you want a leaderboard or top entities, first decide what entity you're ranking:

- **People** → a person-level report such as Influencer Stats, Successful Advocates, or Active Advocates
- **Channels** → Metrics report with the Channel dimension
- **Promotion sources or placements** → Top Promotion Sources report, or Metrics report by the Source dimension
- **Campaign performance** → a campaign export or Metrics report
- **Overall program totals** → a dashboard export or Metrics report

Don't assume a dashboard export is best because it includes the requested metrics. A report can be technically valid and still not be the best fit for your question.

## Summary, Dimensional, and Entity-Level Reports

Extole reports generally fall into three categories.

### Summary Reports

Used for topline totals over a date range. Examples: program dashboard export, campaign dashboard export, Metrics report. Best for executive updates, monthly summaries, and broad performance snapshots.

### Dimensional Reports

Used when performance needs to be grouped by a business dimension. Examples: share channels export, promotions export, Top Promotion Sources report, Metrics report with dimensions. Best for channel comparisons, source analysis, campaign comparisons, and trend analysis over time.

### Entity-Level Reports

Used when each row should represent a specific person or object. Examples: Events report, Successful Advocates report, [Friend Conversion](/guides/dashboards-and-reporting/report-types/rewards-reports/friend-conversion-report) report. Best for advocate leaderboards, person-level investigation, and detailed operational analysis.

## Choosing a Report Based on Intent

If your question includes words like leaderboard, top, rank, best-performing, or who drove the most, identify the ranking dimension before you choose a report. Dashboard exports may contain the requested metrics, but a more specific report may better match your intent.
