# Overview

You pick a program type from the outcome you want, not from the template list. Name the job first — acquisition, retention, or engagement — then pick the program that does that job. If a program you already run covers it, change that one instead of creating another.

For why those three jobs matter, and why most clients run more than one program, see [Why Clients Need More Than Referral](/product/best-practices/program-strategy/why-clients-need-more-than-referral). For the business moments that make a second program the obvious next step, see [Signals You're Ready for a Second Program](/product/best-practices/program-strategy/signals-youre-ready-for-a-second-program).

# Name the Job Before the Program

An outcome is a result you want from customers. A program type is the template that starts with the campaigns, rewards, and rules for that kind of result.

- A first signup or first purchase from someone who is not a customer yet is **acquisition**.
- A reason for someone who already bought to stay is **retention**.
- A specific action from someone who is already a customer — a purchase, an app download, a review — is **engagement**.

The same words can name different jobs. "Reward a purchase" is engagement when your existing customers buy again, and acquisition when a new visitor converts on their first visit. "Thank existing customers" is retention when you want an ongoing relationship, and engagement when you want one action.

# Pick the Program That Does That Job

Pick one type. Name the alternative so you can see what you are not picking. The map of every program type to a job lives on [Why Clients Need More Than Referral](/product/best-practices/program-strategy/why-clients-need-more-than-referral); this table is the common starting points.

| Outcome you have in mind | Job | Program to start from | The alternative |
| :---- | :---- | :---- | :---- |
| Reward people you already have for a purchase or another specific action | Engagement | [Offer / Reward for Action](/product/product-overview/programs/offer/index) | [Welcome Offer](/product/product-overview/programs/welcome-offer/index) if the buyer is not a customer yet |
| Get a first signup or first purchase from someone new | Acquisition | [Welcome Offer](/product/product-overview/programs/welcome-offer/index) | [Refer a Friend](/product/product-overview/programs/refer-a-friend/index) if they should arrive through someone they know |
| Thank existing customers, or keep a selected group in an ongoing relationship | Retention | [Ambassador](/product/product-overview/programs/influencer) | [Loyalty](/product/product-overview/programs/loyalty/index) if they earn points over time rather than join a selected group |
| Grow by having customers bring in people they know | Acquisition | [Refer a Friend](/product/product-overview/programs/refer-a-friend/index) | Welcome Offer if the people you want are not already connected to a customer |

This table is a starting point, not a rulebook. Several outcomes point to the same program, and the right pick still depends on what you already have running.

A purchase reward paid once is an Offer program. A purchase reward that accumulates as points the customer redeems later is a Loyalty program. Ways to earn in loyalty are configured inside a Reward for Action program, so you are still starting from that type — the difference is accumulation, not a one-time payout. See [Loyalty](/product/product-overview/programs/loyalty/index).

# Check What You Already Run

A new program is the right next step when you need a new audience, flow, or reward structure that your existing programs don't cover. If you already run an Offer program that rewards a different action, a second Offer program — or a new campaign in the same program — may be enough. If you already run Refer a Friend and the outcome is still "customers bring friends," change that program rather than starting another.

To tell a new program from a new campaign, see [Programs vs. Campaigns](/guides/platform-overview/programs-vs-campaigns). When the type is chosen, create it from that template — see [Creating a Program](/guides/platform-overview/creating-a-program).
